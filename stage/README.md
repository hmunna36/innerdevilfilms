# stage/: the look of The Devil You Feed since film 07 (17 Nov 2026)

The shared code every new film and Short is drawn with: a near-black stage, cream cartoon people with marker faces, a
black devil with a red glowing edge, handwritten words. It is film 07's own code (`films/07-it-was-so-small`, THE BOTTLE
| It Was So Small) moved here unchanged: 18 stills of the film compared byte for byte before and after the move.

- `rig.js` is the cast and the look and is LOCKED (the owner, 17 Nov 2026: "every video/short should follow this
  direction and character design"). Pose the figures; never redraw them.
- How to build a film or a Short with it: `.claude/skills/idf/reference/engine.md`. The rules: `.claude/skills/idf/SKILL.md`.
- `fonts/`: Balsamiq Sans (SIL Open Font License, `OFL-BalsamiqSans.txt`), loaded as "IDF Hand"; `compare.jpg` shows it
  beside the Mac's Chalkboard SE, which film 07 was delivered in.
- The old films (03-06) and their Shorts are built on `engine/`, which nothing new uses except `engine/audio`
  (mixlib.py, music.mjs) and `engine/qa.mjs`.
